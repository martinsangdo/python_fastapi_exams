Accessibility

We are committed to making ExamPrep accessible to everyone. This page describes accessibility features and contact options for assistance.

Keyboard Navigation

Our site supports standard keyboard navigation. Use Tab/Shift+Tab to move between interactive elements and Enter/Space to activate controls.

Screen Readers

We use semantic HTML and ARIA where appropriate. If you encounter issues with screen reader compatibility, please contact us at accessibility@example.com.

Reporting Issues

Report accessibility barriers or request accommodations by emailing accessibility@example.com with details and steps to reproduce.
