Accessibility

CertQuestionBank is committed to providing an inclusive and accessible learning experience for every student, regardless of ability or assistive technology.

Last updated: June 2026

Keyboard Navigation

All interactive elements are fully reachable and operable using a keyboard alone, with visible focus indicators throughout.

Screen Reader Support

We use semantic HTML5 and ARIA landmarks so screen readers like NVDA, JAWS, and VoiceOver can accurately describe page content.

Colour & Contrast

Text and interactive components meet WCAG 2.1 AA contrast ratios. We do not rely solely on colour to convey meaning.

Keyboard Navigation

Our platform supports standard keyboard navigation patterns throughout:

  • Tab / Shift+Tab — move forward and backward between interactive elements.
  • Enter / Space — activate buttons, links, and controls.
  • Arrow keys — navigate within menus, radio groups, and option lists.
  • Escape — dismiss modals and close dropdown menus.

Screen Reader Compatibility

We have tested our platform with the following screen reader and browser combinations:

  • NVDA with Chrome and Firefox on Windows
  • JAWS with Chrome and Edge on Windows
  • VoiceOver with Safari on macOS and iOS
  • TalkBack with Chrome on Android

If you encounter compatibility issues outside these combinations, please let us know and we will do our best to address them.

Text & Visual Preferences

Our interface respects browser and OS-level accessibility preferences:

  • Text can be resized up to 200% without loss of content or functionality.
  • Layouts reflow at smaller viewports and are fully usable on mobile devices.
  • We honour the prefers-reduced-motion media query to minimise animations for users who are sensitive to motion.
